# 对决三 · 模型架构：Qwen3.8-27B Dense vs Qwen3.8-Flash-Next 125B MoE

> 同一代 Qwen3.8 家族的两种架构路线：稠密 27B（本仓主角）vs 125B MoE（512 专家，每 token 激活 ~6B）。
> Flash-Next 数据来自 NInfer-all 官方参考测量（2026-09/10，桌面 RTX 5090 / 双 5090 工作站）；27B 数据来自本仓实测（RTX 5090 Laptop 24GB）+ 官方参考。**口径不同已标注，趋势可信、绝对值勿横比。**

## 一句话结论

**24GB 单卡笔记本：27B Dense 唯一可行且全面够用；Flash-Next 更聪明，但它的 125B 身躯在这张卡上装不下，专家一挪出 GPU 速度就腰斩再腰斩。**

## 核心对照

| | **27B Dense**（TWIN-TURBO / Coder390） | **Flash-Next 125B MoE** |
|---|---|---|
| 参数 | 27B 全激活 | 125B 总参 / ~6B 激活 / 512 专家 |
| 权重体积 | 15.75-17.3 GB（NVFP4 / Q2-Q3） | Q2_0 **35.9 GiB** + **n-gram 表 26.8 GiB** |
| 24GB 单卡笔记本 | ✅ 权重全在卡上，原生运行 | ❌ 装不下；专家必须放主机内存或磁盘流式 |
| 桌面 5090 短答 decode | 236 tok/s（NInfer 口径，DFlash2） | 136 tok/s（专家全 GPU，**需 2 张卡**） |
| 专家在主机内存 | — | 74 tok/s（比全 GPU −69%） |
| 专家磁盘流式（页缓存） | — | 68 tok/s；冷盘 **25 tok/s** |
| 单卡 24GB 上的现实 | **74-86 tok/s**（llama.cpp / NInfer 实测） | 主机内存路线约 35-53 tok/s 量级（4090 实测折算），磁盘更慢 |
| 质量（官方口径） | Coder390：GPQA 173/198（87.4%）、MMLU 449/500、LCB 92/100 | Q2_0（双 5090）：**AIME 93.3%**、GPQA-Diamond 86.4% |
| n-gram 草稿 | 无（MTP/DFlash2 已够） | 26.8GB n-gram 表（磁盘/内存常驻） |
| 多卡扩展 | 单卡即满血 | 双卡才全 GPU；六请求并发 193 tok/s（双 5090） |

## 怎么读这张表

1. **质量上 Flash-Next 确实强**：AIME 93.3%（奥赛级数学）领先稠密 27B 一个身位——6B 激活量的 MoE 在推理任务上打出了超过 27B 稠密的水平。
2. **但它的胃口是双卡级的**：光权重（Q2_0 压到极限）就要 35.9GB，再加 26.8GB 的 n-gram 表。24GB 笔记本连「专家全 GPU」的门槛都摸不到。
3. **专家流式的代价是残酷的**：专家放主机内存 decode 掉 69%（136→74），放磁盘冷读只剩 25 tok/s——「125B 的智商、个位数的速度」在交互场景不可用。
4. **27B Dense 的价值**：一张 24GB 卡全含（权重 + KV + 视觉 + 7 路并发），每一路 50-80 tok/s。**单卡性价比 = 密度优势。**

## 什么时候该选 Flash-Next

- 你有**两张 24GB+ 卡**（专家全 GPU 需 2×24GB 起步）且要冲数学/推理的绝对上限
- 能接受 35.9GB+26.8GB 的磁盘占用与 n-gram 表常驻
- 推理延迟不敏感（离线批处理）

本仓的答案：在 24GB 笔记本这个约束下，**27B Dense（配合量化与 NInfer/llama.cpp 的并发调优）是唯一正解**——这也是整个调优记录存在的前提。
